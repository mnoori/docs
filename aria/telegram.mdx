[**@AriaMusicBizBot**](https://t.me/AriaMusicBizBot) is the public
Patchline Aria bot on Telegram. Paste a streaming URL, get a rich track
card back, import to catalog, run pitches, ask Aria anything — all
without leaving Telegram.

<TierBadge tier="all" /> &nbsp; Works on every tier including Free. Same AI credit pool as the web dashboard.

## What it does

Telegram is the lightest-weight Aria surface. No browser, no dashboard
context-switch. You're already on Telegram — paste a link, get an
answer.

| Action | How |
|---|---|
| **Track lookup** | Paste a Spotify track URL → rich card with art, metadata, streaming stats |
| **Artist lookup** | Paste an artist URL → roster card + recent activity |
| **One-tap catalog import** | Tap the **Import** button on any track card |
| **Upload your master** | Ask Aria to upload → get an authenticated link → drop the file |
| **Generate cover art** | Describe the cover → Aria runs the same image gen as the web Visual Library |
| **Playlist matching** | Reply to a track card with "find playlists" |
| **DSP pitch draft** | Reply with "pitch this" |
| **Catalog browse** | Type `/catalog` |
| **Roster browse** | Type `/roster` |
| **Aria chat** | Just type your question |

## Quick start

<Steps>
  <Step title="Open the bot">
    Tap [t.me/AriaMusicBizBot](https://t.me/AriaMusicBizBot) on your phone
    or click the link on desktop. Telegram opens to the bot's chat.
  </Step>
  <Step title="Tap Start">
    First-run: tap **Start**. The bot greets you and asks you to link
    your Patchline account (or sign up if you don't have one).
  </Step>
  <Step title="Link your Patchline account">
    The bot sends you a **connection code**. Sign in to Patchline on
    the web, paste the code where the in-app prompt asks for it, and
    your Telegram chat is now bound to your Patchline account.
  </Step>
  <Step title="Paste a track URL">
    Paste any Spotify, YouTube, Apple Music, or SoundCloud track URL.
    Aria returns a rich card.

    <AriaPromptCard prompt="https://open.spotify.com/track/4iV5W9uYEdYUVa79Axb7Rh" surface="telegram" />
  </Step>
</Steps>

## What a track card looks like

When you paste a Spotify URL, the bot replies with:

```text
🎵  Bohemian Rhapsody
    Queen · 1975 · A Night at the Opera

    ⏱  5:55       🎹  E♭ major
    🎼  Streaming stats · audience signal · similar artists
    🎧  Streams (90d): 12,400,000
    📈  Trending: +2.1% mo/mo

    Top genres: rock, classic rock, prog rock

    [ Import to catalog ]  [ Find playlists ]  [ Get pitch ]
    [ Artist intel ]  [ Smart link ]
```

Tap any button. Aria responds inline.

## Uploading audio from Telegram

Want Aria to host your master? Ask in chat:

```text
You: I want to upload my new track
Aria: 🎵 Drop it here →  https://patchline.ai/u/<authenticated-link>
      Link is bound to your Patchline account and expires shortly.
      I'll take it from there.
```

Aria responds with a short-lived, authenticated upload link tied to
your account. You open the link in your browser (the Telegram in-app
browser works too), drop your audio file, and Aria takes over —
captioning, version history, and catalog wiring. You
don't have to come back to Telegram for anything.

Useful when you're recording on your phone or away from your laptop
and want to ship the master without opening the dashboard yourself.

## Generating cover art from Telegram

Aria can generate cover art directly from the Telegram chat. Describe
what you want and Aria runs the same image generation it uses on the
web Visual Library:

```text
You: generate cover art for "Sleeper" — dreampop, late-night,
     muted neon, single figure on a balcony
Aria: 🎨 Working on it…
      [3 image options come back as Telegram media]
      Want me to swap any of these in as the cover for "Sleeper"?
```

Pick one and Aria attaches it to the track in your catalog. From
there it auto-propagates to your storefront and any smart links.

## Commands

You don't need commands for most things — just type or paste a URL
naturally. Telegram-standard `/start` and `/help` are available; for
specific app features, use the menu in the bot reply or just ask
Aria in plain English.

## Where Aria is *not* on Telegram

Some things only work in the web dashboard:

- **Storefront management** — selling music is a web-only flow.
- **Promo flyers & Canvas videos** — flyer and motion-video generation
  stay in the web Visual Library. Cover art generation works on
  Telegram (see above).
- **Project / release planner UI** — you can chat about it on Telegram,
  but the calendar view and project board are web.

## FAQ

<AccordionGroup>
  <Accordion title="Is the bot just a chat wrapper, or is it real Aria?">
    It's real Aria. Telegram talks to the same Aria as
    the web dashboard. The only difference is the UI (text + buttons
    vs. full dashboard chrome).
  </Accordion>
  <Accordion title="Can multiple Telegram accounts link to one Patchline account?">
    Yes. Each Telegram user has their own session, but they all act on
    the same workspace's data. Useful for approved team setups.
  </Accordion>
  <Accordion title="What if I delete the chat?">
    The chat unbinds. Re-link with `/start` next time. Your catalog and
    data stay in Patchline regardless.
  </Accordion>
  <Accordion title="Can I send audio files to the bot?">
    Telegram limits file size to ~50MB for bots. For most masters
    (10–30MB compressed), it works. For large WAVs, use the web
    upload.
  </Accordion>
  <Accordion title="Does the bot work outside the US?">
    Yes — Telegram is global. Some non-US users may see slightly higher
    latency, but most Telegram flows are async and should feel normal.
  </Accordion>
</AccordionGroup>
